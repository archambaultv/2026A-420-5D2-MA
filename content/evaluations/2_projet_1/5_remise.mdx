# La remise

Avant <Echeance id="projet_1" /> :

1. Le dépôt GitHub de l'équipe. S'il est privé,
   ajoutez-moi comme collaborateur (`archambaultv`) ; le paquet ghcr.io devra
   alors être rendu public.
2. Un tag Git `v1` sur le commit remis. Ce qui est poussé après ne compte pas.
3. Sur LÉA : **une seule remise par équipe**, un fichier texte contenant
   - l'URL du dépôt ;
   - le nom des membres de l'équipe ;
   - le tag `sha-` des images à corriger, celui que la chaîne d'intégration
     continue a publié pour le commit marqué `v1`.

C'est ce tag que je mettrai dans mon `.env` pour démarrer votre application.
