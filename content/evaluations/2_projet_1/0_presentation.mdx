# Vue d'ensemble

- **Pondération** : 10 %
- **Modalité** : en équipe de 3 à 4, évaluation individuelle
- **Énoncé distribué** : semaine 4
- **Remise** : dépôt final, <Echeance id="projet_1" />
- **Correction** : entretien **individuel** de 20 minutes, sous forme de revue
  de code, sur rendez-vous. Le lien pour réserver votre plage sera envoyé plus
  tard.
- **Intelligence artificielle** : permise, voir ci-dessous.


## L'intelligence artificielle

Permise, pour tout : le code, les tests, etc. Une seule règle : **tout ce qui
est dans le dépôt doit pouvoir être expliqué**, quel que soit l'auteur, humain
ou non. Par exemple, une personne qui ne sait pas dire ce que fait un test ou pourquoi une
route vérifie ce qu'elle vérifie n'a pas atteint l'objectif, même si le code
marche.

## Le projet 2 sera basé sur le projet 1

Vous garderez la même équipe pour le projet 2 et vous réutiliserez le code du
projet 1.
