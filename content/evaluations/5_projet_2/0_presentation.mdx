# Vue d'ensemble

- **Pondération** : 20 %
- **Modalité** : la même équipe qu'au projet 1, évaluation individuelle
- **Énoncé distribué** : semaine 10
- **Remise** : dépôt final, <Echeance id="projet_2" />
- **Correction** : entretien **individuel** de 20 minutes pendant la semaine
  14, sur rendez-vous. Le lien pour réserver votre plage sera envoyé plus tard.
- **Intelligence artificielle** : permise, voir ci-dessous.

## On repart du projet 1

Le projet 2 continue le projet 1, dans **le même dépôt**. La partie d'échecs
passe en direct : le coup adverse arrive sans attendre, on voit si
l'adversaire est encore là, et d'autres personnes peuvent regarder la partie.

Ce qui était exigé au projet 1 l'est encore, sauf ce que cet énoncé remplace.

## L'intelligence artificielle

Permise, pour tout : le code, les tests, etc. Une seule règle : **tout ce qui
est dans le dépôt doit pouvoir être expliqué**, quel que soit l'auteur, humain
ou non. Par exemple, une personne qui ne sait pas dire ce que le serveur
vérifie à l'ouverture d'une connexion Socket.IO, ni pourquoi, n'a pas atteint
l'objectif, même si le code fonctionne.
