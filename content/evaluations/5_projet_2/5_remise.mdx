# La remise

Avant <Echeance id="projet_2" /> :

1. Le même dépôt GitHub qu'au projet 1. S'il est privé, je dois toujours y
   être collaborateur (`archambaultv`), et le paquet ghcr.io doit être public.
2. Un tag Git `v2` sur le commit remis. Ce qui est poussé après ne compte pas.
3. Sur LÉA : **une seule remise par équipe**, un fichier texte contenant
   - l'URL du dépôt ;
   - le nom des membres de l'équipe ;
   - si vous visez le niveau avancé du critère Livraison : l'adresse publique
     de l'application.
