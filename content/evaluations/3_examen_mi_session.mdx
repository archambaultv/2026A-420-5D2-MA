# Examen de mi-session

- **Pondération** : 30 %
- **Modalité** : individuel, en présentiel
- **Énoncé distribué** : semaine 8
- **Remise** : semaine 8
- **Durée** : 2 heures
- **Documentation** : Aucune documentation permise.

L'examen de mi-session est une épreuve théorique portant sur tous les objectifs
d'apprentissage vus depuis le début du cours. Il consiste principalement en une
série de questions à réponse courte et de questions d'analyse de code.

Voici des exemples de questions à réponse courte :

- Quels sont les avantages d'un rendu côté serveur (SSR) par rapport à un rendu côté client (CSR) ?
- Pourquoi une connexion WebSocket doit-elle commencer par une requête HTTP ?
- Quelle est la différence entre une image Docker et un conteneur Docker ?

Pour les questions d'analyse de code, vous devrez lire un extrait de code,
similaire à celui de QuizM9, et répondre à des questions sur son
fonctionnement, ses erreurs potentielles ou la façon de l'améliorer. Vous
pourriez aussi devoir écrire du code pour compléter ou corriger l'extrait
fourni.
